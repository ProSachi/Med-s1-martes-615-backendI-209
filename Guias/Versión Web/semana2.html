Unidad I: Fundamentos y Modularidad

👨‍🍳 Situación Inicial: El Restaurante Gourmet

Imagina que entras a la cocina de un restaurante. No hay una sola persona haciendo todo; hay una estación de salsas, una de carnes y una de postres.

Cada estación tiene procesos (métodos) que reciben ingredientes (parámetros) y entregan un plato (retorno).

Si la estación de carnes cambia su parrilla, la de postres ni se entera.

Eso es Modularidad.

En Java, no escribimos un "supercódigo" infinito, construimos piezas pequeñas y especializadas.

Colecciones en Java

📚 Colecciones en Java

Son una estructura de datos dentro del paquete java.util diseñada para almacenar, manipular y agrupar objetos como una sola unidad.

Proporcionan una alternativa dinámica y más flexible a los arrays, permitiendo añadir, eliminar, ordenar y buscar elementos eficientemente.

Las principales interfaces son List (ordenada, admite duplicados), Set (elementos únicos) y Map (pares clave-valor).

List (ArrayList)

¿Por qué no usar Arrays simples?

En lógica de programación tradicional, los arreglos tienen un tamaño fijo definido en tiempo de compilación.

En Java, si declaras int[] numeros = new int[5]; no puedes agregar un sexto elemento.

El ArrayList es una implementación de la interfaz List que utiliza un arreglo interno que se redimensiona automáticamente.

¡Crece un 50% de su capacidad cada vez que se llena!

Conceptos Clave

1

Tipos Genéricos (Generics)

Java utiliza <T> para definir qué tipo de objeto guardará la lista. Esto garantiza seguridad de tipos.

2

Wrapper Classes (Clases Envolventes)

Las colecciones NO pueden guardar primitivos (int, double, char). Deben usar sus versiones de objeto: Integer, Double, Character.

3

Índices

Al igual que en la lógica básica, el primer elemento es el 0.

4

Memoria

Un ArrayList mantiene el orden de inserción y permite elementos duplicados.
