# Proyecto de Aula: Backend I en Java

## Descripción del Proyecto
Este proyecto es el resultado de un curso de 18 semanas en el que se desarrolló un sistema de backend utilizando Java. El objetivo principal fue aprender y aplicar conceptos fundamentales de programación, diseño de software y desarrollo de aplicaciones web.

## Objetivos del Proyecto
- **Aprender Java**: Familiarizarse con la sintaxis y las características del lenguaje Java.
- **Desarrollo de API REST**: Crear una API RESTful que permita la interacción con una base de datos.
- **Implementación de Seguridad**: Integrar medidas de seguridad para proteger la información del usuario.
- **Pruebas y Documentación**: Realizar pruebas unitarias y documentar el código para facilitar su mantenimiento.

## Tecnologías Utilizadas
- **Java**: Lenguaje de programación principal.
- **Spring Boot**: Framework para el desarrollo de aplicaciones web.
- **Hibernate**: ORM para la gestión de la base de datos.
- **Maven**: Herramienta de gestión de proyectos y dependencias.
